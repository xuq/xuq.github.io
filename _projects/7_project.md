<h2>鸿蒙“新碰一碰”：手机碰屏幕 / 跨端互联</h2>

<p>
This project page summarizes a HarmonyOS cross-device experience commonly described as “碰一碰” — turning multi-step sharing/connecting workflows into a single, physical gesture.
</p>

<h3>What problem it targets</h3>
<ul>
  <li><strong>Friction</strong>: traditional transfer relies on cables, cloud drives, or multi-step app flows that interrupt thinking.</li>
  <li><strong>Context switching</strong>: users lose attention when the system asks them to pick devices, confirm pairing, or handle permissions repeatedly.</li>
</ul>

<h3>Core experience idea</h3>
<ul>
  <li><strong>Direct manipulation</strong>: “touch device A to device B” maps to “send from A to B”.</li>
  <li><strong>Fusion sensing</strong>: the system can infer <em>where</em> the phone touches and which window/app is the target (as described in IT之家).</li>
  <li><strong>One-step import</strong>: touch a running app window (e.g., editing/creation app) to directly import media/content (as described in IT之家).</li>
</ul>
