<h2 data-i18n-content-key="p3.h2">Keyboard & Mouse Cross-Device Roaming</h2>

<p data-i18n-content-key="p3.intro">I led and delivered a cross-device interaction experience that allows HUAWEI wireless mouse and keyboard to roam across multiple hosts. After pairing with multiple tablets/PCs, users can move the mouse across screen boundaries to switch devices instantly, and the keyboard follows the mouse focus automatically for seamless multi-device productivity.</p>

<h3 data-i18n-content-key="p3.capability.heading">Core Capability</h3>

<ul>
  <li data-i18n-content-key="p3.capability.c1">Supports up to three hosts (tablet/PC) connected to one mouse and one keyboard.</li>
  <li data-i18n-content-key="p3.capability.c2">Mouse cursor crosses device boundaries directly without pressing a manual switch key.</li>
  <li data-i18n-content-key="p3.capability.c3">Keyboard follows the active mouse target automatically, enabling true keyboard-mouse collaboration.</li>
</ul>

<h3 data-i18n-content-key="p3.requirements.heading">Compatibility And Version Requirements</h3>

<ul>
  <li data-i18n-content-key="p3.requirements.r1">Tablet: Bluetooth 5.0+, HarmonyOS 3.0 to HarmonyOS 5.0, Smart Life App 13.0.1.315+.</li>
  <li data-i18n-content-key="p3.requirements.r2">Supported HUAWEI Windows PC: Bluetooth 5.0+, PC Manager 13.0.2.300+.</li>
  <li data-i18n-content-key="p3.requirements.r3">Other PCs: Windows 10+ or macOS 10.15+, with the cross-device client installed.</li>
  <li data-i18n-content-key="p3.requirements.r4">Firmware baseline: mouse 1.0.7.0+, 2.4G receiver 1.0.1.9+, keyboard X.0.0.158+.</li>
  <li data-i18n-content-key="p3.requirements.r5">HarmonyOS 3.0 beta preview does not support this feature; HarmonyOS 3.0 official release does.</li>
</ul>

<h3 data-i18n-content-key="p3.flow.heading">Configuration Flow</h3>

<ol>
  <li data-i18n-content-key="p3.flow.f1">Upgrade required apps/clients and verify host Bluetooth capability.</li>
  <li data-i18n-content-key="p3.flow.f2">Pair mouse/keyboard with one host, then complete peripheral firmware upgrade.</li>
  <li data-i18n-content-key="p3.flow.f3">Repeat pairing for remaining hosts, then enable Mouse Roaming and Keyboard-Mouse Collaboration in device settings.</li>
  <li data-i18n-content-key="p3.flow.f4">Adjust relative host positions in UI and validate boundary crossing in real usage.</li>
</ol>
