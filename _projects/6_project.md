<h2>Huawei M-Pencil Pro（带麦克风的手写笔）</h2>

<p>
This project collects public information about <strong>HUAWEI M-Pencil Pro</strong> — a Huawei stylus that integrates an <strong>omnidirectional microphone</strong> and a <strong>smart button</strong> for quick voice interaction (e.g., wake-up assistant / speech-to-text), designed to pair with selected Huawei tablets.
</p>

<img src="/assets/img/m-pencil-pro/kv.png" alt="HUAWEI M-Pencil Pro product image" style="display:block; width:min(100%, 520px); margin:0 auto 1rem; border-radius:12px;">

<h3>Why it’s interesting (experience opportunities)</h3>
<ul>
  <li><strong>Voice as a first-class input on a pen</strong>: a dedicated smart button + microphone enables a “pen-as-a-voice-gateway” interaction.</li>
  <li><strong>Distributed audio</strong>: pen near-field pickup can complement tablet/PC multi-mic arrays (noise robustness, focus, diarization).</li>
  <li><strong>Trust & control</strong>: physical button interaction can naturally become an explicit privacy/recording gate.</li>
</ul>

<h3>Key public details (from Huawei official pages)</h3>
<ul>
  <li><strong>Smart button + omnidirectional microphone</strong>: quick voice interaction and speech-to-text (features depend on device/model/region/app).</li>
  <li><strong>NearLink</strong>: low-latency and more stable connection (Huawei marketing claim).</li>
  <li><strong>Find my stylus</strong>: supports precise finding and loss reminders (supported devices only).</li>
</ul>
