鸿蒙“新碰一碰”：手机碰屏幕 / 跨端互联

This project page summarizes a HarmonyOS cross-device experience commonly described as “碰一碰” — turning multi-step sharing/connecting workflows into a single, physical gesture.

What problem it targets

  • Friction: traditional transfer relies on cables, cloud drives, or multi-step app flows that interrupt thinking.
  • Context switching: users lose attention when the system asks them to pick devices, confirm pairing, or handle permissions repeatedly.

Core experience idea

  • Direct manipulation: “touch device A to device B” maps to “send from A to B”.
  • Fusion sensing: the system can infer where the phone touches and which window/app is the target (as described in IT之家).
  • One-step import: touch a running app window (e.g., editing/creation app) to directly import media/content (as described in IT之家).
